\section{What is a Resource?}

We classify a resource as a dataset, measurement platform, list, registry, tool or other source of data that is made public and accessible to researchers. This does not include tools or software that generate data or other tools inwhich the independant usage of such tool or software may result in biased data but which is due to fault of the researchers and not of the tool, if the data that is collected from that usage is made a public resource and mentioned in one of the papers we have surveyed, it will be included in the table of resources considered for further analysis.
